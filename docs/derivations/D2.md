# D2 — An AVL tree of height h has at least F(h+3) − 1 nodes, so h < 1.45 log₂(n + 2)

**Author:** Aryan Arya (Structure B owner) · **Roll no.** 250001009 · *draft prepared with Claude, declared in TOOLS.md*

Convention: a single node has height 0, the empty tree height −1. F(1) = F(2) = 1, F(k) = F(k−1) + F(k−2).

**Minimum size.** Let N(h) be the fewest nodes an AVL tree of height h can have. N(−1) = 0, N(0) = 1.
For h ≥ 1 the root has a subtree of height h − 1, and the other subtree has height h − 1 or h − 2; to
minimise, take h − 2 and make both subtrees minimal:

  N(h) = 1 + N(h − 1) + N(h − 2).

Put M(h) = N(h) + 1. Then M(h) = M(h − 1) + M(h − 2), with M(−1) = 1 = F(2) and M(0) = 2 = F(3). So
M(h) = F(h + 3), i.e. **N(h) = F(h + 3) − 1**, and any AVL tree of height h has n ≥ F(h + 3) − 1 nodes.

**Height bound.** With φ = (1 + √5)/2 and ψ = (1 − √5)/2, Binet gives F(k) = (φᵏ − ψᵏ)/√5, and |ψᵏ| < 1,
so F(k) > φᵏ/√5 − 1. Therefore

  n + 2 ≥ F(h + 3) + 1 > φ^(h+3)/√5.

Taking log base φ: h + 3 < log_φ(n + 2) + log_φ √5, so

  h < log₂(n + 2)/log₂ φ + log_φ √5 − 3 = 1.44042… · log₂(n + 2) − 1.32772…

and since the constant term is negative and 1.44042 < 1.45, **h < 1.45 · log₂(n + 2)**. ∎

**Numbers.** N(27) = F(30) − 1 = 832 039 and N(28) = F(31) − 1 = 1 346 268, so a tree of 10⁶ nodes has
height ≤ 27 (our recursion is at most 28 deep). Measured: 10⁶ ascending inserts give height 19;
3·10⁵ random inserts stay under the bound (`tests/test_structB.cpp`).

## Where it is used

- `src/structB/avl_queue.cpp`, `AvlQueue::rebalance` — keeps every balance factor in {−1, 0, 1}, the
  hypothesis of this bound; it is called on the way up in `AvlQueue::insert_rec`, `AvlQueue::delete_rec`
  and `AvlQueue::delete_min_rec`.
- The same file, `AvlQueue::peek_min`, `AvlQueue::successor` and the three recursive functions above —
  each walks at most h + 1 nodes, so the bound makes them O(log n) and keeps the recursion under 30
  levels at n = 10⁶.
- `tests/test_structB.cpp`, `test_height_bound_random` — checks h against this bound with exact constants.
- `docs/MODEL_D6.md` §2 (nodes visited ≤ 1.44·L) and REPORT.md §5 (cost table).
